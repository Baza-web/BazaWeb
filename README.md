# BazaWeb

## Binance API

`src/binance.js` exposes `BinanceClient` (public: `ping`, `time`, `price`, `klines`; signed: `account`).
Set `BINANCE_API_KEY` / `BINANCE_API_SECRET` (and optionally `BINANCE_BASE_URL`, e.g. the testnet) for signed calls. Run tests with `npm test`.
